### 🚀 Features
* **Product Showcase:** Browse and filter various wall art collections.
* **Shopping Cart & Checkout:** Add items to cart and place orders smoothly.
* **Admin Dashboard:** Full control over adding, editing, and deleting products.
* **Responsive UI:** Custom dark burgundy aesthetic styled with CSS.

---

### 🛠️ Tech Stack
* **Frontend:** HTML5, CSS3, JavaScript
* **Backend:** PHP
* **Database:** MySQL

---

### ⚙️ How to Setup & Run

1. **Move Project Folder:**
   * Copy the project folder into your XAMPP `htdocs` directory:
     ```text
     C:\xampp\htdocs\walle
     ```

2. **Database Setup:**
   * Start **Apache** and **MySQL** in XAMPP Control Panel.
   * Open `http://localhost/phpmyadmin`, create a database named `walle`, and import `walle.sql`.

3. **Run Application:**
   * Open your browser and navigate to:
     ```text
     http://localhost/walle/
     ```
